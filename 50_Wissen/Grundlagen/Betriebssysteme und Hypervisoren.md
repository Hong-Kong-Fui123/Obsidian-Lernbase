# Betriebssysteme und Hypervisoren

Thema: [[Hardware]] · [[Windows Server]]

## Was ist ein Betriebssystem?

(Eine Sammlung von Programmen, um mit dem Rechner und der Hardware zu kommunizieren.)

Unter einem Betriebssystem (englisch operating system) versteht man Software, die zusammen mit dem Hardwareeigenschaften des Computers die Basis zum Betrieb bildet und insbesondere die Abarbeitung von Programmen steuert und überwacht.

Beispiele:

-          Apple OS X (Darwin, NetBSD)     - Linux

-          Win 10/Win Server 2019               - Android (Linux)

-          Apple [[IOS]] (auch Darwin)              - usw.

## Unterschied Client- und Serverbetriebssystem

-          Client ist für User und Server für die Server gedacht.

-          Code ist der gleiche.

-          Auswahl der Zusatzprogramme sind unterschiedlich.

-          Client: Maximale Benutzerfreundlichkeit für den Client Betrieb und enthalten standartmäßig **keine** Unternehmenssoftware-Pakete.

## Hypervisoren Typ 1 und Typ 2

## Typ 1

Diese [[Hypervisor]]-Art wird auch Bare-Metal-Hypervisor genannt und läuft

direkt auf der Server-Hardware. Man referenziert die Typ-1-Hypervisoren

oftmals auch als Hardware-Virtualisierungs-Engine.

## Typ 2

Dieser Hypervisor funktioniert als Applikation und läuft entsprechend

auf einem bereits vorhandenen Betriebssystem.
