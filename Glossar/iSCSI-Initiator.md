# iSCSI-Initiator

Client-Seite von iSCSI: verbindet einen Server mit einem [[iSCSI-Target]]; die Datenträger erscheinen dann wie lokale Platten. Dienst `MSiSCSI`, GUI `iscsicpl.exe`.
