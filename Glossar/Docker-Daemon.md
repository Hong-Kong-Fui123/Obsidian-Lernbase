# Docker-Daemon

**Kurz:** Hintergrunddienst, der Images, Container, Netze und Volumes verwaltet.

- Linux: Dienst `docker`, Socket `/var/run/docker.sock`
- Windows: Dienst `docker`, Named Pipe `\\.\pipe\docker_engine`
- Konfiguration: `daemon.json`
