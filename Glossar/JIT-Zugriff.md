# JIT-Zugriff

**Definition:** Defender for Cloud öffnet Management-Ports in der NSG nur auf Anfrage und zeitlich begrenzt.

**Prüfungsfalle:** Benötigt Defender for Servers Plan 2.

**Prüfen:** `Get-AzJitNetworkAccessPolicy`
