# Azure Bastion

**Definition:** Verwalteter RDP/SSH-Zugriff per Browser/TLS auf Azure-VMs ohne öffentliche IP.

**Prüfungsfalle:** Subnetz heißt exakt `AzureBastionSubnet`.

**Prüfen:** `Get-AzBastion`
