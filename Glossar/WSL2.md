# WSL2

**Kurz:** Echter Linux-Kernel in einer leichten Hyper-V-basierten VM unter Windows.

- Installation: `wsl --install` (Windows 11)
- Basis für Linux-Container in Docker Desktop
- Status: `wsl --status`, `wsl -l -v`
