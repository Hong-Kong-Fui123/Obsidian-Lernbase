# Registry

**Kurz:** Server, der Images speichert und verteilt.

- Öffentlich: Docker Hub, `mcr.microsoft.com`, GitHub (`ghcr.io`)
- Privat: eigene Registry, Azure Container Registry
- `docker pull` / `docker push`
