# SMB over QUIC

SMB-Zugriff über **UDP 443** mit TLS 1.3 – sicher über das Internet ohne VPN.

- Server 2025: in Standard, Datacenter und Azure Edition
- Braucht ein Serverzertifikat, dem die Clients vertrauen; Clientzugriffssteuerung möglich
- Clients: Windows 11
