# WDAC

**Definition:** Kernel-erzwungene Positivliste für Code (Treiber, Apps, Skripte).

**Prüfungsfalle:** Erst Audit-Modus, dann erzwingen; AppLocker ist die ältere, benutzerbasierte Variante.

**Prüfen:** `Get-CIPolicy`
