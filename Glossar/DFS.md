# DFS

**Definition:** DFS-N: einheitlicher Namespace über mehrere Server; DFS-R: Multi-Master-Replikation mit RDC.

**Prüfungsfalle:** Migration DFS-R → Azure File Sync möglich.

**Prüfen:** `Get-DfsrBacklog`
