# Checkpoint

**Kurz:** Zeitpunkt-Zustand einer VM (früher Snapshot genannt).

- Standard-Checkpoint: inkl. RAM · Produktions-Checkpoint: VSS-konsistent, ohne RAM
- Kein Backup-Ersatz
- `Checkpoint-VM -Name <VM>` / `Export-VMSnapshot` (Hyper-V-Host)
