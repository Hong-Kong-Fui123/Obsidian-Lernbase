**Hybrid Cloud** = *Hybrid Cloud*
**Deutsch:** Hybride Cloud

Eigene Infrastruktur (On-Premises/Private Cloud) und Public Cloud sind verbunden und arbeiten zusammen.

- Verbindung: VPN-Gateway, ExpressRoute; Verwaltung: [[Azure Arc]]
- Beispiele: lokaler DC + DC-VM in Azure, [[Azure File Sync]]
- Nicht verwechseln mit Multicloud (mehrere Public Clouds)
- Vergleich: [[Cloud-Modelle IaaS PaaS SaaS]] · [[Public Cloud]] · [[Private Cloud]] · [[AZ-802 Übersicht]]
