# Orchestrierung

**Kurz:** Automatische Verwaltung vieler Container über mehrere Hosts.

- Aufgaben: Verteilen, Skalieren, Selbstheilung, Updates
- Werkzeuge: Kubernetes, Docker Swarm, Azure Kubernetes Service
