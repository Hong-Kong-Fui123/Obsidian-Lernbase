# Defender for Servers

Plan in **Microsoft Defender for Cloud**: Antivirus/EDR, Schwachstellenbewertung und Härtungsempfehlungen für Azure-VMs und (über Arc) lokale Server.

- Plan 1: Defender for Endpoint
- Plan 2: zusätzlich z. B. [[JIT-VM-Zugriff]], Dateiintegritätsüberwachung, Updates über Update Manager
