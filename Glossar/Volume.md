# Volume

**Kurz:** Von Docker verwalteter Speicher, der unabhängig vom Container bestehen bleibt.

- Linux: `/var/lib/docker/volumes/`
- `docker volume create|ls|inspect|rm`
- Einsatz: Datenbanken, dauerhafte Daten
