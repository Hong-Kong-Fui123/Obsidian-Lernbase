# Storage Migration Service

Migriert alte Dateiserver auf neue Server oder Azure-VMs – gesteuert über [[Windows Admin Center]].

- Ablauf: **Inventur** → **Übertragung** (Dateien, Freigaben, Rechte) → **Übernahme** (Name und IP des alten Servers)

**Siehe auch:** [[Azure File Sync]] · [[Azure Migrate]]
