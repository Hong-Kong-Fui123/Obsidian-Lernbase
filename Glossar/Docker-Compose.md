# Docker-Compose

**Kurz:** Werkzeug, das mehrere Container, Netze und Volumes in einer YAML-Datei beschreibt.

- Start: `docker compose up -d`, Ende: `docker compose down`
- v2 als Plugin: `docker compose` (ohne Bindestrich)
- Variablen aus `.env`
