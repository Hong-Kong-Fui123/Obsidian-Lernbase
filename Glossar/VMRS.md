# VMRS

**Kurz:** Laufzeitstatus-Datei einer VM (RAM-Inhalt, Saved State).

- CPU-abhängig → Start auf anderem Host kann scheitern
- Vor Export VM herunterfahren oder `Remove-VMSavedState` (Hyper-V-Host)
