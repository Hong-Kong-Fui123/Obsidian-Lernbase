# Azure Migrate

Azure-Dienst, um lokale Server zu **erfassen, bewerten und nach Azure zu migrieren** (Hyper-V, VMware, physisch).

- Ablauf: Appliance erfassen → Bewertung (Größe, Kosten, Bereitschaft) → Replikation → Testmigration → Migration
- Für Dateiserver alternativ [[Storage Migration Service]] oder [[Azure File Sync]]
