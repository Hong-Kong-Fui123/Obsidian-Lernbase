# Hotpatch

Sicherheitsupdates werden **im laufenden Speicher** eingespielt – kein Neustart bis zum nächsten Basis-Update (etwa vierteljährlich).

- Server 2025 Standard/Datacenter über [[Azure Arc]] (Abo-Funktion), Azure Edition in Azure
- Gesteuert über [[Azure Update Manager]]

**Siehe auch:** [[Azure Update Manager]] · [[WSUS]]
