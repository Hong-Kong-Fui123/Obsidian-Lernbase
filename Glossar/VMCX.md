# VMCX

**Kurz:** Binäre VM-Konfigurationsdatei von Hyper-V (ab Server 2016, ersetzt XML).

- Liegt im Ordner `Virtual Machines`, Dateiname = VM-GUID
- Ziel von `Import-VM -Path` und `Compare-VM -Path`
