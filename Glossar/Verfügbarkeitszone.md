# Verfügbarkeitszone

Physisch getrenntes Rechenzentrum innerhalb einer Azure-Region (meist 3 pro Region).

- VMs in mehreren Zonen: SLA 99,99 %
- Schützt gegen Ausfall eines ganzen Rechenzentrums; nur beim Erstellen wählbar
