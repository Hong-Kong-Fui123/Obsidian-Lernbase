# Azure Update Manager

Azure-Dienst für Windows-/Linux-Updates auf Azure-VMs und Arc-Servern: bewerten, sofort installieren oder per Zeitplan.

- Nachfolger von *Update Management* in Azure Automation (eingestellt 31.08.2024), kein Log-Analytics-Agent nötig
- Periodische Bewertung alle 24 h, **Wartungskonfigurationen** für Zeitpläne
- Für Arc-Server kostenpflichtig (Ausnahmen je nach Lizenz/Defender-Plan)
