# Docker-Desktop

**Kurz:** Docker mit grafischer Oberfläche für Windows, macOS und Linux-Desktops.

- Linux-Container unter Windows über WSL2
- Nicht für Windows Server
- Kostenpflichtig für größere Firmen, kostenlos privat/Lernen
