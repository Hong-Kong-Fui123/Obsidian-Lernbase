# iSCSI

**Definition:** Blockspeicher über TCP 3260: Target stellt LUNs bereit, Initiator bindet sie ein.

**Prüfungsfalle:** Zugriff per IQN beschränken, CHAP, MPIO für Redundanz.

**Prüfen:** `Get-IscsiSession`
