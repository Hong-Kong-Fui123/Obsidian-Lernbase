# VCO

Computerkonto eines [[Clientzugriffspunkt]]s einer Clusterrolle (Übung: `FS-Cluster$`). Wird vom [[CNO]] angelegt oder vorab erstellt (Prestaging, CNO bekommt Vollzugriff).
