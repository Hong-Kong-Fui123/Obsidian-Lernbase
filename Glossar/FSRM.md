# FSRM

**Definition:** Kontingente, Dateiprüfungen, Klassifizierung, Berichte, Dateiverwaltungsaufgaben.

**Prüfungsfalle:** Kontingent pro Ordner (FSRM) ≠ Datenträgerkontingent pro Benutzer (NTFS).

**Prüfen:** `Get-FsrmQuota`
