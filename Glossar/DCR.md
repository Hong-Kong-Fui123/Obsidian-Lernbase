# DCR

**Definition:** Legt fest, welche Daten der Azure Monitor Agent sammelt und wohin sie gehen.

**Prüfungsfalle:** AMA + DCR ersetzen den abgekündigten MMA.

**Prüfen:** `Get-AzDataCollectionRule`
