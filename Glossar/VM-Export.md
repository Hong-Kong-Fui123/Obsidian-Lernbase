# VM-Export

**Kurz:** Kopie einer VM (Konfiguration, Festplatten, Checkpoints) in einen portablen Ordner.

- Cmdlet: `Export-VM -Name <VM> -Path <Ziel>` (Hyper-V-Host)
- Live-Export bei laufender VM möglich, sauberer: VM vorher herunterfahren
- Kein Ersatz für eine Backup-Strategie
