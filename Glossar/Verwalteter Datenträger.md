# Verwalteter Datenträger

Virtuelle Festplatte einer Azure-VM, die Azure als eigene Ressource verwaltet.

- Typen: Standard-HDD, Standard-SSD, Premium-SSD (v2), Ultra Disk
- Nur vergrößern, nie verkleinern; Hostcache: Keine / Lesen / Lesen+Schreiben
- Temporärer Datenträger (meist D:) ist **kein** verwalteter Datenträger und geht verloren
