# VHDX

**Kurz:** Virtuelles Festplattenformat von Hyper-V, max. 64 TB, ausfallsicherer als VHD.

- Typen: feste Größe · dynamisch · differenzierend
- Größe prüfen: `Get-VHD -Path <datei>` → `FileSize` (Hyper-V-Host)
